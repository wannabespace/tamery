Choose **Microsoft SQL Server** under **Engine**, or paste:

```text
sqlserver://user:password@localhost:1433/mydb
```

`mssql://` works too. The default port is **1433**. JDBC, ADO.NET, and ODBC strings and `sqlcmd` commands work as well.

## Azure SQL

Use the server name and database from your Azure connection details:

```text
sqlserver://user:password@your-server.database.windows.net:1433/mydb?encrypt=true&trustServerCertificate=false
```

Allow your IP address in the server's firewall settings. In the web app, allow [the cloud proxy's addresses](/connections/security#cloud-proxy-ip-addresses) instead.

## Encryption

Connections are encrypted by default. The certificate is not checked unless you ask for it.

| Option | Behavior |
| --- | --- |
| `trustServerCertificate=false` | Verify the server's certificate. Use this for Azure SQL and anything public. |
| `trustServerCertificate=true` | Skip the check. Fine for a local server with a self-signed certificate. |
| `encrypt=false` | No encryption. |

For localhost in the web app, run the [local proxy](/cli/commands#tamery-proxy).
