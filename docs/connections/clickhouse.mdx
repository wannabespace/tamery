Tamery talks to ClickHouse over its **HTTP interface**. Click **New connection** and paste an HTTP or HTTPS connection string. ClickHouse 21.12 or later is supported.

## ClickHouse Cloud

Copy the HTTPS details from your service's **Connect** panel:

```text
https://default:password@your-service.clickhouse.cloud:8443/default
```

## Local server

```text
http://default:password@localhost:8123/default
```

Leave out `:password` if the user has none.

Use port **8123** for HTTP or **8443** for HTTPS. The native ports **9000** and **9440** don't work over HTTP, so Tamery switches a pasted 9000 or 9440 to 8123 or 8443.

When you fill in the fields yourself, Tamery uses HTTPS unless the port is 8123 or empty.

## Differences to know

- ClickHouse has no transactions. Schema changes apply one at a time.
- Columns can't be renamed.
- Sorting-key columns, `MATERIALIZED` and `ALIAS` columns can't be edited in the table browser.
- The sorting key isn't unique, so Tamery finds the rows to change by their values. Identical rows can't be told apart: an edit or delete reaches all of them, and Tamery tells you how many before it runs.
- Row policies show up under [Schema → Policies](/features/definitions).

For localhost in the web app, run the [local proxy](/cli/commands#tamery-proxy).
