## DuckDB files

DuckDB files open in the desktop app. Drop the file onto Tamery, or choose **DuckDB** under **Engine** and pick the file with the folder button.

Pasting a path works too, as long as the file ends in `.duckdb` or `.ddb`. For any other name, paste `duckdb /path/to/file` or a URL:

```text
duckdb:///Users/me/analytics.duckdb
```

The file must already exist. A `~/` path points to the home folder of whichever computer opens it. Syncing the connection does not copy the file.

Tamery opens the file only while it runs a query. Another program that has the file open for writing, like the `duckdb` CLI, keeps Tamery out until it closes the file, and the other way around.

In a query you can read files and URLs straight away, like `SELECT * FROM read_csv('~/Downloads/orders.csv')`. Read-only queries an agent runs through [MCP](/mcp/overview) can't: they see only the database file itself.

The web app and [`tamery bridge`](/cli/overview) don't open DuckDB files.

## MotherDuck

Choose **MotherDuck** and enter your access token. Create one in MotherDuck under **Settings → Access Tokens**. Leave **Database** empty to see every database in your workspace.

Pasting an `md:` string fills in the form:

```text
md:my_db?motherduck_token=your-token
```

Tamery reaches MotherDuck through its Postgres endpoint. **Host** starts as `pg.us-east-1-aws.motherduck.com`. If your organization is in another region, use that region's host, like `pg.eu-central-1-aws.motherduck.com`. Pasting the endpoint's `postgresql://` URL from MotherDuck sets the host for you.

MotherDuck works in both the desktop and web apps. The token follows the same [sync rules](/connections/overview#choose-what-syncs) as a password.

## What works

Browse and edit rows, run SQL, explore relationships, and manage schemas, views, and indexes.

- You can add, rename, and drop columns, and change a column's type or nullability. DuckDB refuses to change a column that an index or key covers.
- Existing constraints are read-only. DuckDB adds no constraint to a table after it was created.
- Lists, structs, and maps edit as JSON.
- On MotherDuck, queries can't read files on your computer.
