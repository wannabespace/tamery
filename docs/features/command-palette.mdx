Press **Cmd+P** (**Ctrl+P**), or click the ⌘ button in the title bar. Type a few letters of what you want.

From the palette you can:

- Open any connection, or any table in the current one
- Start a new query, table, view, schema, or column
- Open a schema page or the visualizer
- [Copy the current PostgreSQL database](/features/copy-database) into another one
- Refresh the data in the current tab
- Show or hide the Navigator, the AI chat, and the query logger
- Switch between light, dark, and system theme
- Open a settings section, reload the window, or check for updates on desktop

If you are not sure where something lives, try the palette first.

## Keyboard shortcuts

Tamery works fine with a mouse. These save a few clicks if you like the keyboard.

| Action | macOS | Windows / Linux |
| --- | --- | --- |
| Command palette | Cmd+P | Ctrl+P |
| Settings | Cmd+, | Ctrl+, |
| Search the current page | Cmd+F | Ctrl+F |
| Show or hide the Navigator | Cmd+B | Ctrl+B |
| AI chat | Cmd+L | Ctrl+L |
| Query logger | Cmd+J | Ctrl+J |
| Open the right-click menu of what has focus | Cmd+. | Ctrl+. |
| Save staged changes | Cmd+S | Ctrl+S |
| Undo / redo a staged change | Cmd+Z / Cmd+Shift+Z | Ctrl+Z / Ctrl+Shift+Z |
| Grid or documents view | Cmd+Shift+E | Ctrl+Shift+E |
| Delete ticked rows | Cmd+Backspace | Ctrl+Backspace |
| Step back out of whatever is open | Esc | Esc |

Desktop adds **Cmd+N** for a new connection, **Cmd+T** and **Cmd+W** for tabs, **Cmd+Shift+N** for a new window, and **Cmd+R** to refresh. Use **Ctrl** instead of **Cmd** on Windows and Linux.

**Tab** moves focus between the Navigator, the tab bar, the toolbar, and the grid. Arrow keys move within each.

The Query editor has its own [run and save shortcuts](/features/query-editor#run-queries).

The full list, with search, is in **Settings → Keyboard**. Turn on **Show shortcuts while holding** there, then hold **Cmd** (**Ctrl**) for a moment to see each control's shortcut on top of it.
