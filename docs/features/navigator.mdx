## Navigator

The Navigator is the sidebar of an open connection. It lists your schemas and tables, with **Schema** at the top for [indexes, constraints, and the rest](/features/definitions). **Cmd+B** (**Ctrl+B**) hides it.

Start typing in its search field to find a table. Arrow keys walk the list, and **Enter** opens the highlighted table with the grid ready for the keyboard.

Right-click a table to:

- **Pin** it to the top of the list, for the tables you open every day
- **Rename** or **Drop** it
- **Copy Name**
- **Open in New Window**, on desktop

Each schema has a **+** for a new table. Right-click a schema for **New View**, **Rename**, **Copy Name**, or **Drop**. **New schema** sits below the last schema.

What you can rename or create depends on the engine. SQLite and ClickHouse have no schemas to manage, for example.

The connection's home page lists the tables you opened recently, so you can jump back in. A database with no tables yet offers **New table** there instead.

## Tabs

Clicking a table opens it in a preview tab, shown in italics. The next table you click replaces it. Double-click the table in the Navigator to keep its tab open.

You can open as many query tabs as you like. Each table, schema page, or the visualizer opens once.

Double-click a tab to rename it. Right-click it to close it, the others, everything to its left or right, or all of them. **Reset Name** in the same menu brings back the original title.

The arrows at the start of the tab bar go back and forward through the tabs you visited. On desktop, **Cmd+T** (**Ctrl+T**) opens a new tab and **Cmd+W** (**Ctrl+W**) closes the current one.

Tabs are remembered per database on this device. When you start Tamery again, it opens where you left off.

## Windows

On desktop, **Cmd+Shift+N** (**Ctrl+Shift+N**) opens another window. **Open in New Window** on a connection or a table opens it straight there. Handy for comparing two databases side by side.

The desktop title bar also has **Open in web app**, which opens the same page in your browser. It shows up only for connections synced as **Full** that don't use an SSH tunnel, because those are the ones the browser can open on its own.
