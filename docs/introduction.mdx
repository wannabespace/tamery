Tamery helps you tame your queries across PostgreSQL, TimescaleDB, MySQL, MariaDB, SQL Server, Oracle, ClickHouse, MongoDB, and SQLite, including Turso and Cloudflare D1.

Use it on [macOS, Windows, or Linux](/installation), or [in your browser](https://web.tamery.app).

> The name came after an earlier one. It is **tame** plus **query**, a fun meaning we could play with. The French will like it too.

## What you can do

| Task | Where to go |
| --- | --- |
| Find, filter, and edit rows without SQL | [Table browser](/features/table-browser) |
| Write SQL, inspect results, and save queries | [Query editor](/features/query-editor) |
| Export rows or turn a table into code | [Export and code](/features/export) |
| See how tables connect and change their structure | [Schema visualizer](/features/schema-visualizer) |
| Manage indexes, constraints, functions, and more | [Schema](/features/definitions) |
| Get SQL explanations, edits, and error fixes | [AI assistant](/features/ai-assistant) |
| Send anyone a read-only link to a table | [Sharing tables](/features/sharing) |
| Let your coding agent use your connections | [MCP](/mcp/overview) |
| Run queries from your terminal | [CLI](/cli/overview) |

Your connections sync across devices. You decide per connection whether the password comes along. See [Choose what syncs](/connections/overview#choose-what-syncs).

## Get help

Pick **Support** in the avatar menu to write to us directly. It lands with the people who build Tamery.

Found a bug or want something changed? Open an [issue on GitHub](https://github.com/wannabespace/tamery/issues). We also hang out on [Discord](https://discord.gg/XweDPUVadR).

What changed in each version is in the [release notes](https://tamery.app/releases).
