## Desktop

[Download Tamery](https://tamery.app/download) for macOS, Windows, or Linux. Use desktop for local databases, SQLite files, SSH tunnels, and [MCP](/mcp/overview).

- **macOS:** pick Apple silicon or Intel, open the `.dmg` and drag Tamery to **Applications**. Or use Homebrew, which needs macOS 12 or later:

  ```bash
  brew install --cask tamery
  ```

- **Windows:** run the `.exe` installer.
- **Linux:** choose the `.deb`, `.rpm`, or AppImage. On Arch, install `tamery-bin` from the AUR.

Windows and Linux builds are 64-bit x86 only.

To sign in, the app opens your browser. The page shows which device asked and a code: continue only if the app shows the same code and you started signing in yourself. Someone who sends you a sign-in link of their own gets a different code.

## Updates

The desktop app checks for updates every 10 minutes and downloads them in the background. When one is ready, **Restart to update** appears in the title bar. Click it when it suits you; nothing restarts on its own.

To check right now, click the version number in the title bar, or choose **Check for updates…** in the [command palette](/features/command-palette).

## Web

Open [web.tamery.app](https://web.tamery.app) and sign in. Public database servers work without installing anything.

For localhost, private networks, or SQLite files, keep [`tamery bridge`](/cli/overview) running on the computer that can reach them. It opens SSH tunnels too.

## CLI

`tamery bridge` lets the web app reach databases through your computer. Install it with one command on macOS, Linux, or Windows, or with npm. See [Install](/cli/overview#install).
