`tamery --help` (`-h`) lists every command. `tamery --version` (`-v`) prints the version.

## tamery bridge

```bash
tamery bridge
```

Lets the web app run your connections on this computer until you press **Ctrl+C**. If the computer isn't signed in yet, it opens the browser to sign in first. [Tamery CLI](/cli/overview#run-the-bridge) walks through pairing.

It prints the account, the address it listens on, a pairing link and code, a line for each browser that pairs, and requests it refused because of a wrong host or origin.

| Flag | Use |
| --- | --- |
| `--port <port>` | Listen on another port. The default is `26380`. |
| `--public-url <url>` | The HTTPS address a tunnel or reverse proxy on this computer serves the bridge at. See [Reach a bridge on another computer](/cli/remote). |

If the port is taken, usually by another bridge, it says so and exits. Stop the other one or pass `--port`.

## tamery bridge unpair-all

```bash
tamery bridge unpair-all
```

Disconnects every paired browser. Each one needs a new pairing link from `tamery bridge`. Saved secrets stay.

## tamery logout

```bash
tamery logout
```

Signs the CLI out of your account and deletes what it stored on this computer: the session, the saved secrets, their key in the keychain, and every pairing. The next `tamery bridge` signs in again, so this is also how you switch accounts.
