To run queries on a machine from another computer, give it an `https://` address. On the same computer you don't need one.

**Use Tailscale if you can**: its network is private. Cloudflare Tunnel and ngrok put the address on the public internet, and they can read your queries, results and the secrets you send. Either way, the machine runs nothing until you allow your app on it.

1. On the machine's computer, start one of the services below.
2. Give the machine the address it shows:

   | Machine | Port | Address |
   | --- | --- | --- |
   | Desktop app | `26382` | **Settings → Machines → Address for your other computers** |
   | CLI | `26380` | `tamery machine --public-url <address>` |

3. On your other computer, choose the machine under a connection's **Runs on**, then allow it on the machine within 2 minutes. Over SSH, use [`tamery machine approve`](/cli/commands#tamery-machine-approve) (CLI only).

The commands below use the desktop app's port. For the CLI, use `26380`, or the port you passed to `--port`.

## Tailscale

Install [Tailscale](https://tailscale.com/download) on both computers, sign in to the same tailnet, and run on the machine's computer:

```bash
tailscale serve --bg 26382
```

Don't use `tailscale funnel`, which makes the address public.

## Cloudflare Tunnel

Install [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) and run:

```bash
cloudflared tunnel --url http://127.0.0.1:26382
```

This address changes every time. For a permanent one, create a tunnel in the Cloudflare dashboard with the service URL `http://127.0.0.1:26382`. Requests longer than about 2 minutes fail.

## ngrok

Install [ngrok](https://ngrok.com/download), add your authtoken and run:

```bash
ngrok http 26382
```

## Caddy

On a server with its own domain, add this to the `Caddyfile`:

```text
db-box.example.com {
  reverse_proxy 127.0.0.1:26382
}
```

## Another service

Any tunnel or reverse proxy works if it runs on the machine's computer, serves HTTPS and forwards the original `Host` header.
