The machine listens only on `127.0.0.1`, so other computers can't reach it directly. To use a machine on a server or another computer, run a tunnel or reverse proxy **on that same computer**, give it an HTTPS address, and pass that address to `tamery machine --public-url`. The web app connects only to `127.0.0.1` or an `https://` address.

Reaching the address is not enough to use the machine: a browser runs nothing until you allow it in the machine's terminal or with `tamery machine approve`.

A request through a tunnel without `--public-url` gets an error that tells you which address to set.

## Tailscale Serve

Tailscale Serve gives the machine an HTTPS address that only devices on your tailnet can open. The encryption ends on the machine's computer, so nothing in between sees your queries.

1. On the machine's computer, run:

   ```bash
   tailscale serve --bg 26380
   tamery machine --public-url https://<machine>.<tailnet>.ts.net
   ```

   The first time, Tailscale asks you to turn on HTTPS for your tailnet.

2. Open the pairing link in a browser on a device in the same tailnet.

## Cloudflare Tunnel

1. On the machine's computer, start a tunnel to the machine's port:

   ```bash
   cloudflared tunnel --url http://127.0.0.1:26380
   ```

2. Start the machine with the address `cloudflared` printed:

   ```bash
   tamery machine --public-url https://<name>.trycloudflare.com
   ```

That address changes every time. A named tunnel with your own hostname works the same way and keeps it.

Know two limits before you use it:

- Cloudflare ends any request after 100 seconds, so a query that runs longer fails.
- Cloudflare decrypts the traffic on its servers. It can see your queries, their results, and the secrets you enter for **No password** and **Metadata only** connections, which go to the machine once. If that matters, use Tailscale Serve.

## Caddy

On a server with a domain pointing at it, Caddy gets a certificate on its own. Add this to the `Caddyfile` on the machine's computer:

```text
db-box.example.com {
  reverse_proxy 127.0.0.1:26380
}
```

Then start the machine:

```bash
tamery machine --public-url https://db-box.example.com
```

Any other reverse proxy works the same way, as long as it runs on the machine's computer, serves HTTPS, and forwards the original `Host` header.
