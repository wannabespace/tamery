## Install and sign in

You need **Node.js 22.16 or later**.

```bash
npm install -g tamery
tamery login
```

Finish signing in in the browser, with the same account you use in the app.

## Run a query

The CLI uses the connections you saved in Tamery. Find the name of the one you want:

```bash
tamery query --list-connections
tamery query -c my-db "SELECT 1 AS hello"
```

It also runs SQL files and prints JSON. See [all commands](/cli/commands).

## Reach local databases from the web

```bash
tamery proxy
```

Keep it running on the computer that can reach the database. The web app finds it on its own. **Ctrl+C** stops it.

The proxy also opens SQLite files on that computer. SSH tunnels still need the desktop app.
